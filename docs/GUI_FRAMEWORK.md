**组成部分**:

- **底部面板**: AI对话、终端、输出、任务详情（可展开/收起）

#### 4. GUI启动入口
- **文件**: `gui_main.py`
- **用法**: `python gui_main.py`

### 🎨 主要组件

#### MainWindow类

**核心方法**:
```python
# UI初始化
_init_menubar()          # 菜单栏（文件、视图、项目、帮助）
_init_toolbar()          # 工具栏（快速操作按钮）
_init_central_widget()   # 中央三栏布局
_init_statusbar()        # 状态栏

# 布局创建
_create_sidebar()        # 项目浏览器树
_create_central_tabs()   # 中央标签页
_create_bottom_panel()   # 底部面板
_apply_stylesheet()      # 应用亮色主题

# 公共API
add_central_tab(widget, title, closable)  # 添加标签页
log_ai_message(role, message)             # 记录AI消息
log_output(message)                       # 记录输出日志
update_status(message)                    # 更新状态栏
```

### ✨ 已实现的功能

#### 菜单栏
- **文件菜单**: 新建项目、打开项目、退出
- **视图菜单**: 切换侧边栏(Ctrl+B)、切换底部面板(Ctrl+J)
- **项目菜单**: 需求分析(Ctrl+Shift+A)、任务看板(Ctrl+Shift+T)
- **帮助菜单**: 关于

#### 工具栏
- 新建、打开
- 需求分析、任务管理、项目监控

#### 侧边栏
- 项目树形浏览器
- 展开/折叠项目结构
- 悬停高亮

#### 中央区域
- 多标签页系统
- 可关闭标签（欢迎页除外）
- 可拖动标签重排序
- 欢迎页（快速开始按钮）

#### 底部面板
- **AI对话**: 显示多角色讨论
- **终端**: 命令行输出（暗色终端风格）
- **输出**: 系统日志
- **任务详情**: 任务信息

#### 状态栏
- 左侧: 当前状态
- 右侧: 项目信息、AI角色数、任务数
