## 关键要点

1. **一次一个任务**：按顺序执行，确保依赖关系正确
2. **详细回答问题**：需求分析时提供详细信息，任务会更精确
3. **利用Claude Code**：将任务指令提供给Claude Code，它会自动实现
4. **定期检查进度**：使用CLI工具查看项目状态
