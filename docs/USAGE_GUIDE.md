## 快速开始

### 1. 创建新项目

```bash
python src/main.py
```

系统会引导您完成以下步骤：
1. 输入项目名称
2. 描述高层目标
3. 回答7个澄清问题
4. 自动生成需求文档和任务列表

### 2. 查看生成的文件

完成后，系统会创建以下结构：

```
projects/PRJ-XXXXXXXX/
├── docs/
│   ├── PRD.md              # 项目需求文档
│   └── TASKS_SUMMARY.md    # 任务摘要
├── src/                    # 源代码目录（待实现）
├── .ai_tasks/              # AI任务指令文件
│   ├── TASK-XXXXXXXX.md
│   └── ...
└── project.json            # 项目状态文件
```

### 3. 执行任务

有两种方式执行任务：

**方式A：手动执行**
```bash
# 查看下一个任务
python src/cli_tools.py ./projects/PRJ-XXXXXXXX next

# 阅读任务指令
cat ./projects/PRJ-XXXXXXXX/.ai_tasks/TASK-XXXXXXXX.md

# 手动编写代码...
```

**方式B：使用Claude Code（推荐）**
```bash
# 将任务指令提供给Claude Code
# Claude Code会读取任务文件并自动实现
```

## 系统架构

```
┌─────────────────────────────────────────────┐
│          用户（提供高层目标）                 │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│   AI需求分析师（交互式澄清需求）             │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│  PRD（项目需求文档 - 单一事实来源）          │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│  AI任务分解器（生成任务队列）                │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│  任务指令文件（.ai_tasks/）                  │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│  Claude Code执行任务                         │
└─────────────────────────────────────────────┘
```

### 核心组件

1. **RequirementAnalyst（需求分析师）**
   - 生成澄清问题
   - 记录用户回答
   - 生成用户故事
   - 推断技术栈

2. **TaskDecomposer（任务分解器）**
   - 将用户故事分解为任务
   - 处理任务依赖关系
   - 生成任务指令文件

3. **ProjectManager（项目管理器）**
   - 协调整个流程
   - 管理项目状态
   - 持久化数据

## 工作流程

### 阶段1：需求分析

系统会问您7个问题：

1. 主要用户群体？
2. 核心功能（3-5个）？
3. 技术栈偏好？
4. 数据存储方式？
5. 运行环境？
6. 规模和性能要求？
7. 是否需要第三方集成？

**示例对话：**

```
❓ 问题 1/7: 这个项目的主要用户群体是谁？
💬 你的回答: 个人用户

❓ 问题 2/7: 请列出您认为最核心的3-5个功能（按优先级排序）
💬 你的回答: 添加待办事项，查看列表，删除，标记完成

...
```

### 阶段2：任务规划

系统自动：
1. 分析您的回答
2. 生成用户故事
3. 将用户故事分解为具体任务
4. 建立任务依赖关系
5. 生成任务指令文件

### 阶段3：任务执行

您可以：
1. 使用CLI工具查看任务
2. 将任务指令提供给Claude Code
3. 手动实现（如果您愿意）

## CLI工具使用

### 查看下一个待执行的任务

```bash
python src/cli_tools.py <project_path> next
```

输出示例：
```
======================================================================
📋 下一个任务
======================================================================

任务ID: TASK-12345678
标题: 创建项目目录结构
类型: setup

描述:
创建标准的项目目录结构：
- src/：源代码目录
...

验收标准:
  1. 项目目录结构清晰规范
  2. README.md包含项目基本信息
  ...

📄 任务详细指令: ./projects/PRJ-XXX/.ai_tasks/TASK-12345678.md
======================================================================
```

### 查看所有任务

```bash
python src/cli_tools.py <project_path> list
```

### 查看特定任务详情

```bash
python src/cli_tools.py <project_path> task TASK-12345678
```

### 查看PRD文档

```bash
python src/cli_tools.py <project_path> prd
```

## 与Claude Code协作

### 工作模式

AI-Exchange-Room生成的任务指令专为Claude Code设计。每个任务文件包含：

- **任务描述**：清晰的目标说明
- **上下文信息**：项目背景和技术栈
- **验收标准**：明确的完成条件
- **技术要点**：实现建议

### 推荐工作流

**步骤1：获取任务**
```bash
python src/cli_tools.py ./projects/PRJ-XXX next
```

**步骤2：提供给Claude Code**
```
请阅读以下任务指令并实现：
./projects/PRJ-XXX/.ai_tasks/TASK-XXX.md
```

**步骤3：Claude Code执行**
Claude Code会：
- 阅读任务文件
- 理解需求和验收标准
- 实现代码
- 保存到项目的src/目录

**步骤4：标记完成（可选）**
```python
from src.core import ProjectManager
pm = ProjectManager()
pm.mark_task_completed(project, "TASK-XXX", ["file1.py", "file2.py"])
```

### 协作示例

**用户：**
```
我想创建一个待办事项应用
```

**AI PM（通过main.py）：**
```
✅ 已生成13个任务
📄 下一个任务：创建项目目录结构
```

**用户→Claude Code：**
```
请执行任务：./projects/PRJ-ABC/tasks/TASK-001.md
```

**Claude Code：**
```
✅ 已完成！
- 创建了src/、tests/、docs/目录
- 生成了README.md
- 配置了.gitignore
```

## 高级用法

### 自定义需求分析问题

编辑 `src/core/requirement_analyst.py` 中的 `generate_clarification_questions()` 方法。

### 自定义任务分解规则

编辑 `src/core/task_decomposer.py` 中的分解逻辑。

### 添加自定义任务类型

在 `src/models/task.py` 中添加新的 `TaskType` 枚举值。

### 项目模板

创建项目模板：

```python
from src.core import ProjectManager

pm = ProjectManager()
project = pm.create_new_project("模板项目", "通用Web应用模板")
# ... 自定义配置
pm.save_project(project)
```

## 常见问题

### Q: 如何修改已生成的需求？

A: 目前需要重新运行需求分析。未来版本将支持需求变更管理。

### Q: 任务执行顺序是如何决定的？

A: 基于任务的依赖关系。系统确保依赖任务完成后才执行后续任务。

### Q: 可以手动添加任务吗？

A: 可以。直接编辑项目的JSON文件或使用ProjectManager API。

### Q: 支持团队协作吗？

A: v0.1版本主要面向个人使用。团队协作功能计划在未来版本添加。

### Q: 如何与现有项目集成？

A: 当前版本主要用于新项目。现有项目集成功能正在开发中。

### Q: 生成的任务太多/太少怎么办？

A: 可以调整 `TaskDecomposer` 的分解粒度，或在需求分析时提供更详细的信息。

## 最佳实践

1. **明确高层目标**：在需求分析时，尽可能详细描述您的目标
2. **优先级排序**：列出核心功能时，按实际优先级排序
3. **逐个执行**：按顺序执行任务，不要跳过
4. **及时反馈**：发现问题及时记录
5. **保持同步**：定期查看项目仪表板了解进度
