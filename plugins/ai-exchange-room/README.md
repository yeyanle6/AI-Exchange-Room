# AI-Exchange-Room 插件

## 概述

AI-Exchange-Room是一个AI驱动的自动编程系统，作为AI ToolBox的核心插件之一。

## 功能特性

### 1. 多角色需求分析 ⭐
- 6个AI专家角色协同分析需求
- 实时可视化讨论过程
- 结构化需求输出

### 2. 任务看板
- 看板式任务管理
- 待办/进行中/已完成三列布局
- 任务拖拽和状态切换

### 3. 监控仪表板
- 实时项目指标
- 进度可视化
- 活动日志

## 使用方法

1. 在工具箱首页点击"AI-Exchange-Room"卡片
2. 使用顶部菜单或工具栏打开各功能模块
3. 快捷键:
   - `Ctrl+Shift+A`: 需求分析
   - `Ctrl+Shift+T`: 任务看板

## 技术栈

- **后端**: Python, MultiAgentAnalyst
- **前端**: PyQt5
- **架构**: MVC分离
